# 观梅数 · 象数推演台

一个纯前端实现的梅花易数 / 小六壬起卦推演网页，适合传统文化研习与趣玩（非决策建议）。

## 功能特性

- **梅花易数模块**：支持手动与时间起卦，体用生克、互卦变卦完整推演流程
- **小六壬模块**：九宫（大安至天德）掐指起卦，三传连读，附民俗化解参考
- **六十四卦数据**：内置完整卦辞，随机起卦即时断吉凶
- **交互动效**：太极八卦旋转动画、掐指演示，视觉风格贴合传统美学
- **响应式布局**：桌面 / 移动端自适应，单文件 `index.html` 即可运行

## 技术栈

HTML5 / CSS3 / 原生 JavaScript，无框架、无构建工具、零依赖，部署即开即用。

## 在线运行

仓库仅含一个 `index.html`，下载后双击即可在浏览器打开；也可参照 [部署指南](./部署指南_CloudflarePages.md) 通过 Cloudflare Pages 免费部署并绑定自定义域名。
